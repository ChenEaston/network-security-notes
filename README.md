## 记录原则

- 注明设备型号、软件版本、适用条件与记录日期。
- 区分官方公告分析、源码审阅、本地实测和待验证假设。
- 命令附用途、参数说明及预期判断；变更操作说明影响与回退方法。
- 实际测试才记录为实测结果，资料分析不能代替实验。
- 公开材料不包含客户身份、真实业务拓扑、密码、令牌或未经允许公开的信息。
- 发现错误后补充更正和依据，保留修改记录。
